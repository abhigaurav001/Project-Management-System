# Project-Management-System
The Project Management System is a web-based application designed to help individuals and teams efficiently manage projects, tasks, and deadlines. It provides a centralized platform where users can create projects, assign tasks, track progress, and monitor project status in an organized manner.
# 🚀 ProjectHub - Project Management System

A modern, feature-rich **Project Management System** built with vanilla **HTML, CSS, and JavaScript**. Manage projects, tasks, teams, and deadlines all in one place with a beautiful, responsive UI.

## ✨ Features

### 📊 Dashboard
- Real-time statistics cards (Projects, Tasks, Members)
- Project progress visualization
- Interactive task distribution donut chart
- Recent activity timeline
- Upcoming deadlines tracker

### 📁 Project Management
- Create, Edit, Delete projects
- Detailed project information (Category, Budget, Client, Tech stack)
- Priority levels (Low, Medium, High, Critical)
- Status tracking (Active, On Hold, Completed)
- Grid and List view modes
- Advanced filtering and sorting
- Team member assignment

### 📋 Task Board (Kanban)
- Drag-and-drop task management
- 4 columns: To Do → In Progress → Review → Completed
- Task tagging system
- Priority indicators
- Due date tracking
- Estimated hours
- Assignee avatars

### 👥 Team Management
- Add/Remove team members
- Role and department tracking
- Individual member statistics
- Contact information storage

### 📅 Calendar
- Monthly calendar view
- Deadline visualization
- Interactive navigation
- Timeline of upcoming deadlines

### 📈 Reports & Analytics
- Project summary reports
- Task completion analytics
- Team workload distribution
- Completion overview charts

### 🎨 Additional Features
- 🌙 **Dark Mode** toggle
- 🔍 **Global Search** (Ctrl+K shortcut)
- 💾 **LocalStorage** persistence
- 📤 **JSON Export** functionality
- 🔔 **Toast Notifications**
- 📱 **Fully Responsive** design
- ⚡ **No Dependencies** (Pure vanilla JS)
